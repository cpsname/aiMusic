# App Store preview upload checklist — Songlet

Generated by `store-preview checklist --app songlet` from `store_preview/songlet/`; edit those
files, not this one. Rules: docs/store/apple-preview-rules.md (packages/store_preview).

Files: `dist/songlet/<localization>/<script>.mp4`, with `<script>.poster.png`,
`<script>.captions.srt` (every text on screen) and `<script>.edl.json` (what is footage,
what is not, every licensed item).

## Before uploading

1. `store-preview validate --app songlet` passes all three layers (spec, compliance, narrative).
2. Watch each preview muted: the intro card and the first caption state the claim on their own.
3. The app version under review ships everything the previews show.
4. The end card discloses the purchase: "Requires a subscription or credits" (en-US; localized in each).

## Every localization

**iPhone 6.9" Display** — upload in this order (the first autoplays):
1. `A.mp4` — A song with their name in it (25 s)
2. `B.mp4` — Your photos set the mood. Share the video. (25 s)

**Poster frame.** App Store Connect uses 0:05 unless told otherwise.
Upload tools that set one still frame for every preview (fastlane deliver's `preview_frame_time_code`) use `00:00:13:00`: it lies on the finished product in every preview (A: player, B: lyricVideo). Uploading by hand, set each preview's own:
